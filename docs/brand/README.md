# Brand assets

## super-productivity-mcp

These files are unchanged copies from the super-productivity-mcp site pack in
SUBCULT Studio (`subculture-collective/subcult-tv`,
`studio/brands/super-productivity-mcp/`) at revision `159489c`. The owner
accepted the pack on October 13, 2026. The masters live in Studio. Do not edit
these copies; change the pack in Studio and copy the new files here.

Text in the lockup is converted to paths, so no font is needed. The lockup is
drawn in light colours for dark backgrounds. The README shows it when the
reader's browser requests a dark colour scheme and otherwise shows the one-
colour mark for light backgrounds. The pack has no lockup for light backgrounds.
