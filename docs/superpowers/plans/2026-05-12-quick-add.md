# Quick Add Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use TDD. Steps use checkbox (`- [ ]`) syntax for tracking. Do not commit unless the user asks.

**Goal:** Add an Omarchy/Hyprland-friendly `sp-quick-add` helper that opens a global quick-add prompt and creates Super Productivity tasks through existing IPC.

**Architecture:** Hyprland owns the global hotkey. `sp-quick-add` owns prompt, input validation, task creation, and notifications. Prompt implementation is isolated so Walker can be replaced later by a richer UI.

**Tech Stack:** Go 1.22, existing `internal/config`, `internal/pluginipc`, `internal/domain`, Walker, Hyprland.

---

## File Map

- Create `internal/quickadd/quickadd.go`: core prompt/task/notify orchestration and interfaces.
- Create `internal/quickadd/quickadd_test.go`: unit tests for no-op, dry-run, direct title, prompt path, notify errors.
- Create `cmd/sp-quick-add/main.go`: CLI flags and real adapters for Walker, IPC, notify-send.
- Modify `scripts/install.sh`: build/install `sp-mcp` and `sp-quick-add`.
- Modify `README.md`, `CONTRIBUTING.md`: document quick add, install, tests.
- Modify `~/.config/hypr/bindings.conf`: add `SUPER SHIFT T` binding with the installed absolute binary path after verification.
